# Offline copy of the prototype

`BENI-Airport-Offline.html` is a single file with every page, the English/French switch and the Landing photo. Double-click it to open in Chrome, Edge or Firefox. No internet needed (the Plus Jakarta Sans font loads only when online; otherwise a system font is used).

- It is a design preview: data you type is saved only in that browser on that computer.
- `dcmini.js` is the small runtime that draws the pages. The page sources are embedded in the HTML.
- Sign-in on the first screen only gates that screen. The live system will use a secure account login.

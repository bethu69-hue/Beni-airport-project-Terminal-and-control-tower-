# Glossary (must match the already-translated Monthly Report page)
Employer = Maître de l'Ouvrage; Contractor = Entrepreneur; Engineer = Ingénieur; Contractor's Documents = documents de l'Entrepreneur
Notice = Notification; Notice of Claim = Notification de Réclamation; Claim = Réclamation; Variation = Modification
EOT / Extension of Time = Prorogation du délai (EOT -> "PD" not needed; keep "EOT" only if it stands alone as a label: "Prorogation (EOT)")
Time for Completion = Délai d'achèvement; Taking-Over Certificate = Certificat de réception; Defects Notification Period (DNP) = Période de notification des défauts (DNP)
DAAB = DAAB (Commission d'adjudication/d'évitement des différends); keep the acronym DAAB, IPC (Interim Payment Certificate) = Certificat de paiement intermédiaire (IPC); NCR = NCR (Rapport de non-conformité); RFI = RFI (Demande d'information)
Particular Conditions = Conditions Particulières; General Conditions = Conditions Générales; Contract Data = Données du Contrat; Employer's Requirements = Exigences du Maître de l'Ouvrage
Approved for Use = Approuvé pour utilisation; Not Configured = Non configuré; Extracted but Unverified = Extrait mais non vérifié; Under Review = En cours de revue; Verified = Vérifié; Superseded = Remplacé
Project Manager = Chef de projet; Assistant Project Manager = Chef de projet adjoint; Contract Manager = Gestionnaire de contrat
Draft = Brouillon; Overdue = En retard (orange, never red wording); Programme = Programme; Site = Chantier
Prototype = Prototype. Keep brand/proper names, people names, clause numbers, abbreviations, file names, numbers, symbols (● ▲ ○ ✓ ■ → ·) and punctuation unchanged.
Tone: formal professional French suitable for a DRC construction project. Use "vous". Keep length similar so layouts do not break.
